# 🏏 Hardik Pandya Bio Webpage

A simple and responsive **biography webpage dedicated to Hardik Pandya**, one of India's prominent all-round cricketers. The website presents his personal background, cricket career, achievements, and career statistics in a clean and visually appealing layout.

The project is built using **HTML5 and CSS3 only**, without JavaScript or any backend.

## 🌟 Features

* 📱 Responsive and clean webpage design
* 🏏 Detailed biography of Hardik Pandya
* 📖 Personal and professional journey
* 🏆 Cricket career information
* 🏟️ IPL career details
* 🌍 ODI, Test, and T20I career information
* 🏆 World Cup information
* 🖼️ Profile image section
* 📊 Quick-reference information table
* 🎨 Modern styling using CSS
* 💻 No JavaScript required
* ⚡ Lightweight static website
* 🔧 Easy to customize and update

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling and responsive layout
* **Flexbox** – Page layout
* **CSS Gradients** – Visual effects
* **CSS Shadows** – Modern card and section styling

## 🚀 How to Run Locally

### Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/hardik_site.git
```

### Step 2: Navigate to the Project Folder

```bash
cd hardik_site
```

### Step 3: Open the Website

Simply open:

```text
index.html
```

in any modern web browser.

No server or additional installation is required.

## 🌐 Deploy Using GitHub Pages

You can easily host this static website using **GitHub Pages**.

### Steps

1. Create a new GitHub repository.
2. Upload `index.html`, CSS files, and images.
3. Go to **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select:

   * Branch: `main`
   * Folder: `/root`
6. Click **Save**.

Your website will then be available at:

```text
https://kavaliakhilandeshwari45.github.io/hardik_site/
```

## 🖼️ Image Setup

The webpage uses a Hardik Pandya image stored at:

```text
static/images/hardik.jpg
```

Make sure the image exists at this location.

You can replace the image with another suitable image while keeping the same filename, or update the image path in `index.html`.
